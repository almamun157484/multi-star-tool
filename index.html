⭐ মাল্টি-অ্যাকাউন্ট স্টার টুল

আপনার নিজের একাধিক GitHub অ্যাকাউন্টের টোকেন দিয়ে একটি রিপোজিটরিতে একসাথে স্টার দিন।

⚠️ শুধু নিজের মালিকানাধীন অ্যাকাউন্টের জন্য ব্যবহার করুন। অন্য কারো অ্যাকাউন্ট দিয়ে বা ভাড়া করা/কেনা অ্যাকাউন্ট দিয়ে স্টার বাড়ানো GitHub-এর নিয়ম ভঙ্গ করে এবং এতে অ্যাকাউন্ট সাসপেন্ড হতে পারে। এখানে পাসওয়ার্ড নয়, শুধু Personal Access Token ব্যবহার হয়।
প্রতিটি টোকেন public_repo পারমিশনসহ বানাতে হবে। টোকেন কোথাও সেভ হয় না, সরাসরি GitHub-এ যায়।
টোকেনগুলো এই পেজে থাকা অবস্থায় যেকোনো রিপোর লিংক বদলে আবার স্টার/আনস্টার করা যাবে — একই টোকেন একাধিক রিপোজিটরির জন্য বারবার ব্যবহার করা যায়।
